# 🥦 Gıda İsrafı Analizi ve Makine Öğrenmesi ile Tahmini
Bu proje, gıda israfı ile ekonomik kayıp arasındaki ilişkiyi incelemeyi ve makine öğrenmesi algoritmaları ile gıda israfının gelecekteki ekonomik kaybını tahmin etmeyi amaçlamaktadır. 
Proje, veri ön işleme, görselleştirme, ve çeşitli makine öğrenmesi modellerinin (Random Forest, XGBoost) uygulanmasını içermektedir.

# 🎯 Projenin Amacı:
-Gıda Kategorilerindeki Ekonomik Kayıpları belirlemek ve görselleştirmek.

-Ülkeler bazında toplam atık miktarını analiz ederek bir bar plot grafiği ile görselleştirmek.

-Yıllara göre kişi başına düşen ortalama atık miktarını inceleyip line plot grafiğiyle sunmak.

-Random Forest Regressor kullanarak kişi başına düşen atık miktarını tahmin etmek ve çeşitli performans metrikleri kullanarak model başarısını değerlendirmek.

-Boxplot kullanarak tahmin sonuçlarının dağılımını görselleştirmek.

-XGBRegressor ile ekonomik kayıp tahminini yapmak.

-Ekonomik kayıp ile toplam atık arasındaki korelasyonu analiz etmek ve bunu scatter plot grafiğiyle görselleştirmek.

# 📈 Görselleştirmeler:
-Pie Chart

-Bar Plot

-Line Plot

-Boxplot

-Scatter Plot

# 🧹 Veri Temizleme ve Dönüştürme:
-Eksik Veriler: Eksik veriler kontrol edilip uygun yöntemlerle dolduruldu.

-Kategori Verilerinin Sayısallaştırılması: Kategorik veriler, modellerde kullanılmak üzere sayısal verilere dönüştürüldü.

-Aykırı Değerlerin Düzeltilmesi: Aykırı değerler belirlendi ve uygun şekilde ele alındı.

-Veri Ölçekleme: Özelliklerin ölçeklenmesi ile modelin daha doğru sonuçlar vermesi sağlandı.
